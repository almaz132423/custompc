# Импорт PC Part Dataset

Разовый импорт комплектующих из [docyx/pc-part-dataset](https://github.com/docyx/pc-part-dataset) в таблицу `Component`.

Импортируются категории, которые используются текущим конфигуратором CustomPC:

- CPU
- GPU
- MOTHERBOARD
- RAM
- SSD (из `internal-hard-drive.json`)
- PSU
- CASE
- COOLING

Источник содержит характеристики и snapshot цены в USD. Цена не преобразуется в рубли и не считается актуальной магазинной ценой.

## Запуск

Из каталога `backend`:

```bash
npm run import:pc-parts
```

Скрипт сам загружает JSON-файлы из репозитория dataset и выполняет upsert в PostgreSQL.

## Что сохраняется

Полные исходные поля записи сохраняются в `Component.specs`, вместе с метаданными `_dataset.source`, `_dataset.version`, `_dataset.category` и URL исходного JSON.

В `Component.compatibility` дополнительно нормализуются поля, которые уже понимает движок совместимости CustomPC:

- motherboard: `socket`, `formFactor`;
- RAM: `ramType`, `modules`;
- GPU: `lengthMm`;
- PSU: `powerW`;
- CASE: `formFactor`.

Важно: в исходном dataset нет socket у CPU и данных о поддерживаемых сокетах у кулеров, поэтому скрипт не придумывает эти значения. Существующие правила совместимости продолжат работать для данных, где необходимые поля действительно присутствуют.

## Повторный запуск

Импорт использует детерминированные ID, поэтому повторный запуск обновляет уже импортированные строки вместо создания дублей.

Записи с отсутствующей или некорректной ценой пропускаются, потому что текущая модель `Component.price` обязательна.

## Ограничение источника

Dataset содержит snapshot данных PCPartPicker; цены и наличие не следует считать текущими данными магазина. Способ регулярного обновления можно реализовать отдельно, когда это понадобится.
